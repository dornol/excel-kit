Group Subtotals

groupSubtotal(key, ...) writes a SUBTOTAL formula row after every run of rows with an equal key. Sales data is fixed (East, North, South, West: 6 rows each) so the numbers can be checked by hand. Rows must be sorted by the key.

Basics - A SUBTOTAL row below every region and a grand total that does not count the subtotals twice. Edit a Units/Amount cell in Excel: the subtotals and the total follow

Every function - sum, average, count (numbers), countA (every non-empty cell, text included), min and max per column, in the subtotal rows and in the summary

Layout - Merged region cell, zebra stripes, a page per region, filter, freeze and a custom subtotal style. keyColumn("Region") shows the region in its subtotal row: filter Region = East and the East subtotal stays

Rollover - 24 rows over sheets of 10 (maxRows): each sheet closes its last region and has its own total; row numbers skip the subtotal rows

Sheet protection - Data columns are editable, the subtotal rows stay locked (password: 1234)

Rules over subtotal rows - Conditional format (> 2,500), a region dropdown and a Units validation also run over the subtotal rows

Workbook - A sheet with subtotals next to a plain sheet of the same data in one ExcelWorkbook

Product data - Random products sorted by category, subtotal of price and quantity per category

Unsorted input (contract) - The rows are not sorted by the key, so every run gets its own subtotal: sort the data by the key first

Refused combination - table(...), chart(...) and namedRange(...) cannot be combined with subtotals: shows the error message
