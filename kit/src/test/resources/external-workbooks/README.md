# External workbook compatibility fixtures

These binaries are copied **unchanged** from the Apache POI repository at commit
[`521b26fad979c1992538584c199fc75f2a1fd7aa`](https://github.com/apache/poi/tree/521b26fad979c1992538584c199fc75f2a1fd7aa/test-data).
They are not generated by excel-kit or re-saved by POI during tests. Tests run
entirely offline and verify SHA-256 checksums before/after exercising reader APIs.
They belong to test resources and are not packaged in the published library JAR.

| File | Embedded producer metadata | Covered behavior |
| --- | --- | --- |
| `WithVariousData.xlsx` | Microsoft Excel / AppVersion 12.0000 | Shared strings, numeric cells, sparse physical rows, comments, sheet/header discovery |
| `DateFormatTests.xlsx` | Microsoft Macintosh Excel / AppVersion 16.0300 | 1904 date system, custom date/time formatting, cached text formulas, date-valued header extraction |
| `shared_formulas.xlsx` | Microsoft Excel / AppVersion 12.0000 | Cached string values with shared-formula markup |
| `59775.xlsx` | LibreOffice 5.0.3.2 (Linux) | Hyperlink text and gaps in physical row numbering |
| `60384.xlsx` | LibreOffice 5.1.4.2 (Linux) | Merged text blocks, sparse cells, formatted decimal values |
| `tile-range-test.xlsx` | LibreOffice 5.3.4.2 (Windows) | Two-sheet package sharing, cached numeric/shared formulas, formula-policy rejection |
| `70005-countifs.xlsx` | LibreOffice 25.2.7.2 (Linux) | Cached array-formula results without recalculation |
| `60320-protected.xlsx` | Microsoft Macintosh Excel / AppVersion 15.0300, inspected after decryption | Encrypted Path/stream/source reads, incorrect passwords, ownership and plaintext-workspace cleanup |

Producer names/versions above are **document metadata**, not authenticated evidence
of the application that last edited a file. Tests check representative fields and
fixed expected values. Formatted-value assertions use POI's thread-local US locale
so OS language settings do not change the oracle. This corpus does not establish compatibility with every
version or feature of Excel/LibreOffice. Numeric formula results are cached values;
excel-kit does not evaluate these formulas.

All files except `60320-protected.xlsx` come from `test-data/spreadsheet/`;
`60320-protected.xlsx` comes from `test-data/poifs/`. Their immutable source URL is:

```
https://raw.githubusercontent.com/apache/poi/521b26fad979c1992538584c199fc75f2a1fd7aa/<upstream-directory>/<filename>
```

`SHA256SUMS` records the exact downloaded bytes. Replacements require a deliberate
source/version/checksum update and a review of the literal expected values. Do not
regenerate this corpus with the library under test.

The public fixture password is `Test001!!`, taken from upstream
[`TestDecryptor.bug60320`](https://github.com/apache/poi/blob/521b26fad979c1992538584c199fc75f2a1fd7aa/poi-ooxml/src/test/java/org/apache/poi/poifs/crypt/tests/TestDecryptor.java).
The worksheet itself says it was created with Excel for Mac 2011 and re-encrypted
by Mac Excel 2016. This is sample data, not a deployment credential. The matching constant has a
line-scoped `ggignore` annotation for this documented public test credential;
secret scanning remains enabled for the rest of the repository.
